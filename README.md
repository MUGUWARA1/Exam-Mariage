# Wedding Management System - Backend

## Overview

The Wedding Management System backend is a Spring-based application designed to facilitate the management of wedding events. It provides essential functionalities for handling guest details, managing guest accommodations, and coordinating wedding schedules.

## Features

- **Guest Management:** 
  - Add, update, and remove guest information.
  - Track RSVPs and dietary preferences.

- **Room Management:** 
  - Manage guest accommodations.
  - Handle room assignments and availability.

- **Wedding Management:** 
  - Organize and schedule wedding events.

## Technology Stack

- **Backend Framework:** Spring
- **Database:** [ MySQL, PostgreSQL]
- **Other Technologies:** [Hibernate, JPA ,...]

## Getting Started

To get started with the Wedding Management System backend, follow these steps:

1. **Clone the Repository:**

    ```bash
    git clone https://github.com/yourusername/wedding-management-backend.git
    ```

2. **Navigate to the Project Directory:**

    ```bash
    cd wedding-management-backend
    ```

3. **Build the Project:**

    If you are using Maven:

    ```bash
    mvn clean install
    ```

    If you are using Gradle:

    ```bash
    ./gradlew build
    ```

4. **Run the Application:**

    You can run the application with the following command:

    ```bash
    mvn spring-boot:run
    ```

    or

    ```bash
    ./gradlew bootRun
    ```

    Ensure that you have configured your environment variables and database settings as required.
